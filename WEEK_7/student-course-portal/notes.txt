angular.json - Stores the Angular project configuration, including build, serve, test, and project settings.

tsconfig.json - Defines the TypeScript compiler options and project-wide TypeScript settings.

tsconfig.app.json - Contains the TypeScript compiler settings specific to the Angular application.

package.json - Contains the project's metadata, scripts, dependencies, and development dependencies.

src/main.ts - The application's entry point that bootstraps the Angular application.

src/app/app.config.ts - Configures the application's providers, routing, and other application-level settings. (Angular standalone projects use this instead of AppModule.)

src/app/app.ts - Defines the root App component and its logic.

src/index.html - The main HTML page that hosts the Angular application.

Compiled application code: main-NLVIHSGWP.js

Production budgets in angular.json control the maximum bundle size. Angular shows a warning if the bundle exceeds maximumWarning and fails the build if it exceeds maximumError.
